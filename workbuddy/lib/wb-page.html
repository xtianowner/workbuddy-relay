1填写 API Key

导入时 Key 会写入本机 WorkBuddy 配置；运行日志不记录 Key。

2选择模型和思考强度

勾选模型思考强度

导入前会逐个试一下：模型不可用就不导入；选了思考强度但服务不支持的，会自动改成「关闭」并在结果里说明。导入后在 WorkBuddy 里也能随时切换思考强度。

3导入

运行日志

日志保存在本机，自动保留最近 30 天，最多 40 MB。遇到导入失败时，点击导出，把压缩包发给客服排查。
