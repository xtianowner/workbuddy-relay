WorkBuddy 中转站一键导入

把 new-api / sub2api 中转站的模型导入 WorkBuddy，每个模型可单独选思考强度

检测中…
  1. 1填地址
  2. 2获取 Key
  3. 3选模型
  4. 4导入

1中转站地址

就是你平时用浏览器打开中转站的那个网址。

2获取 Key

在中转站网页的「令牌 / API 密钥」页点复制，粘贴到这里。

3选择模型和思考强度

勾选模型思考强度

导入前会逐个试一下：模型不可用就不导入；选了思考强度但中转站不支持的，会自动改成「关闭」并在结果里说明。导入后在 WorkBuddy 里也能随时切换思考强度。

4导入
