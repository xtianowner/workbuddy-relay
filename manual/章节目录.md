# workbuddy-relay 使用手册 · 章节目录（v2.2.1）

HTML 与 PDF 共用同一份源文件 `manual.html`，章节编号一致。

1. 下载
2. 双击运行（2.1 Windows / 2.2 Mac / 2.3 打开后的页面）
3. 填写站点地址
4. 获取 Key（4.1 new-api 平台令牌 / 4.2 选择一个 Key / 4.3 sub2api 或直接粘贴 Key）
5. 选择模型和思考强度
6. 导入并查看结果
7. 在 WorkBuddy 里确认
8. 常见问题（8.1–8.9）
9. 反馈问题（GitHub Issues）

## 生成
- 截图：`python3 manual/capture.py`（用 headless Chromium 跑网页模式端到端，对接本地模拟中转站，截图写到 `manual/img/web-*.png`；令牌输入框为密码框，Key 只显示打码后的形式）
- 成品：`./build-manual.sh` → `out/workbuddy-relay使用手册-v<版本>-<日期>.html/.pdf`
