# workbuddy-relay 使用手册 · 章节目录（v2.1.0）

HTML 与 PDF 共用同一份源文件 `manual.html`，章节编号一致。

1. 下载
2. 双击运行（2.1 Windows / 2.2 Mac / 2.3 运行后会看到什么）
3. 填写站点地址
4. 拿平台令牌，或直接粘贴 Key（4.1 new-api 令牌 / 4.2 sub2api / 4.3 直接粘贴 / 4.4 令牌填错）
5. 选择 Key，等待导入完成
6. 在 WorkBuddy 里确认
7. 常见问题（7.1–7.7）
8. 反馈问题（GitHub Issues）

## 生成
- 截图：`cd ../workbuddy/test/e2e && OUT=/tmp/shots python3 ../../../manual/capture.py`，再在 /tmp/shots 下运行 `render.py`（终端截图来自本地模拟站点的真实运行结果，令牌和 Key 已打码，临时目录显示为 ~）
- 成品：`./build-manual.sh` → `out/workbuddy-relay使用手册-v<版本>-<日期>.html/.pdf`
