workbuddy-relay 使用手册

版本 v2.2.3 · 2026-10-24

这个小工具能把你在中转站（new-api 或 sub2api 搭建的网站）上的 API Key，一键导入到 WorkBuddy 里。导入以后，你就能在 WorkBuddy 里直接选用中转站提供的模型，不用再手动填地址、复制 Key。

1 下载

使用前，电脑上要先装好 WorkBuddy（https://www.workbuddy.cn/）。

打开下载页 https://github.com/xtianowner/workbuddy-relay/releases/latest，在页面底部的「Assets」里，按你的电脑选一个下载：

你的电脑下载这个文件
Windowsworkbuddy-relay-2.2.3-win.zip
Mac（M1/M2/M3/M4 等 Apple 芯片）workbuddy-relay-2.2.3-mac-arm64.zip
Mac（Intel 芯片）workbuddy-relay-2.2.3-mac-x64.zip
不知道 Mac 是哪种芯片？点屏幕左上角苹果图标 →「关于本机」，「芯片」一栏写着 Apple M… 就是 Apple 芯片，写着 Intel 就是 Intel。

下载后双击 zip 解压，会得到一个文件夹，里面有程序和一份 README.txt。

【缺图 1-1】GitHub Release 页面 Assets 区域，标出要点的下载文件

2 双击运行

2.1 Windows

双击 WorkBuddy-Relay-Import.exe。程序会自动用你的默认浏览器打开一个导入页面，接下来所有填写都在这个网页里完成。同时会出现一个黑色小窗口，它是网页背后的程序，导入完成前不要关掉它。

第一次运行时，Windows 可能弹出蓝色提示「Windows 已保护你的电脑」。点「更多信息」，再点「仍要运行」就行。出现这个提示是因为程序没有做商业签名，并不代表有病毒。

【缺图 2-1】Windows SmartScreen 提示框，标出「更多信息」和「仍要运行」

2.2 Mac

双击 WorkBuddy-Relay-Import。系统会先打开一个「终端」窗口（网页背后的程序，导入完成前不要关掉），然后自动用默认浏览器打开导入页面。

第一次打开时，Mac 可能提示「无法打开，因为无法验证开发者」。处理方法：

  1. 先点「完成」或「好」，把提示关掉；
  2. 打开「系统设置」→「隐私与安全性」，往下翻，会看到一句「已阻止使用 WorkBuddy-Relay-Import」，点它旁边的「仍要打开」；
  3. 输入开机密码确认，然后再双击一次程序。

在较早的 macOS 版本上，也可以在程序上点右键 →「打开」→「打开」。

【缺图 2-2】macOS 无法验证开发者的提示框
【缺图 2-3】系统设置 → 隐私与安全性里的「仍要打开」按钮

2.3 打开后的页面

页面右上角会显示是否检测到 WorkBuddy。页面分 4 步，从上往下填写就行，完成一步下一步才会亮起来。

图 2-1　刚打开的导入页面。

如果浏览器没有自动打开，黑色窗口（Mac 是终端窗口）里会显示一个以 http://127.0.0.1: 开头的地址，把它整段复制到浏览器地址栏打开即可。这个页面只在你自己的电脑上运行，别人访问不到。

3 填写站点地址

在第 1 步「中转站地址」里，填你平时用浏览器打开中转站的那个网址，比如 https://api.example.com，点「下一步」。

程序会自动识别这个站点是 new-api 还是 sub2api，识别成功会显示绿色的 ✓。

图 3-1　识别为 new-api 后，第 2 步亮起（令牌输入框里的内容会显示成圆点）。截图来自本地测试站点，所以地址是 127.0.0.1，你看到的会是自己中转站的网址。

如果显示「未能识别平台类型」，也没关系，接下来直接粘贴 Key 就能继续。

4 获取 Key

第 2 步有两种方式，点上方的按钮切换：

  • 用平台令牌自动获取：程序把你账号里已有的 Key 列出来让你选，也可以帮你新建一个。new-api 推荐用这个。
  • 我已复制好 Key，直接粘贴：在中转站网站上复制好 Key，粘贴进来。sub2api 推荐用这个（识别为 sub2api 时会自动切到这里）。

4.1 new-api：获取平台令牌

  1. 用浏览器登录你的中转站；
  2. 进入「个人设置」→「访问令牌」→「新建」；
  3. 把 api_key:read、api_key:reveal、api_key:write 这三项权限都勾上；
  4. 复制生成的那串以 nap_ 开头的令牌，粘贴到导入页面的令牌框里，点「读取我的 Key」。
【缺图 4-1】new-api 网页「访问令牌」新建界面，标出三个权限勾选框和复制按钮

4.2 选择一个 Key

读取成功后会列出你账号里能用的 Key（只显示开头和结尾几位）。点选一个，或者选最下面的「新建一个 WorkBuddy 专用 Key」，然后点「下一步：读取模型」。

图 4-1　读取到已有 Key，默认选中第一个。

4.3 sub2api 或直接粘贴 Key

在中转站网站的「API 密钥 / 令牌」页面点复制，回到导入页面点「我已复制好 Key，直接粘贴」，粘贴后点「下一步：读取模型」。

【缺图 4-2】sub2api 网页「API 密钥」页面，标出复制按钮
令牌读不出 Key（比如令牌填错、权限没勾全）时，页面会用红字说明原因，你可以改正后重试，或者切到「直接粘贴」。

5 选择模型和思考强度

第 3 步会列出这个 Key 能用的聊天模型（向量、图片等非聊天模型已自动去掉）。

  • 勾选你要导入的模型。默认勾选前 12 个，可以点「全选」「全不选」；
  • 每个模型右边可以选思考强度：自动（实测）/ 关闭 / 低 / 中 / 高。默认是「自动（实测）」：导入时程序会给每个模型真实发一次很小的请求，中转站接受思考参数就按「中」导入，不接受就关闭；你也可以手动指定；
  • 想统一设置，可以在右上角「把勾选的都设为」里选一个。

图 5-1　勾选模型，并给每个模型选思考强度。

这里选的是默认思考强度。导入后，在 WorkBuddy 里也能随时为每次对话切换「低 / 中 / 高」。思考强度越高，回答越慢、消耗的额度越多。

6 导入并查看结果

点第 4 步的「导入到 WorkBuddy」。程序会逐个测试模型，几秒到几十秒后显示结果表：

  • 已导入：模型能用，按你选的思考强度导入了；
  • 已导入·已降级：模型能用，但这个中转站不支持给它设思考强度，已改成「关闭」导入，「说明」一栏会写原因；
  • 未导入：模型现在调不通（比如没有可用渠道），没有导入。

图 6-1　导入完成。截图中 claude-sonnet-4 被测试站点拒绝了思考参数，已自动降级；broken-model 不可用，没有导入。

看到绿色的「完成：已导入 N 个模型」就成功了。点「完成，关闭本工具」，程序会退出，浏览器页面可以直接关掉。忘了点也没关系，程序会在导入完成 2 分钟后自动退出。

7 在 WorkBuddy 里确认

  1. 回到 WorkBuddy，不需要重启；
  2. 点输入框上方的模型选择器；
  3. 往下翻到「自定义 / Custom」分组，能看到刚导入的模型就说明成功了；
  4. 选中一个设了思考强度的模型，可以在模型信息里看到「思考强度」并切换；
  5. 发一句话试试看。

8 常见问题

8.1 提示没有检测到 WorkBuddy

先安装 WorkBuddy 并至少打开一次，然后重新运行本工具。

8.2 Windows 提示「已保护你的电脑」，Mac 提示「无法验证开发者」

见第 2 章，按步骤放行即可。

8.3 浏览器没有自动打开 / 页面显示「链接已失效」

复制黑色窗口（Mac 是终端窗口）里显示的完整地址到浏览器打开。如果程序已经关掉了，重新双击运行即可，每次运行地址都会变。

8.4 某个模型显示「未导入」

说明中转站这个模型现在调不通，比如没有可用的渠道，或者余额不足。程序只会导入能用的模型，等站点那边恢复后再运行一次就行。

8.5 一个能用的模型都没有

请检查三件事：Key 是否复制完整、Key 在网站上是否处于启用状态、账户余额是否充足。

8.6 某个模型「已降级」，没有思考强度

说明这个中转站对该模型不接受思考参数（常见于站点没有为 Claude、Gemini 做转换）。模型本身照常能用，只是不带思考。可以联系站长开启，开启后重新运行本工具即可。

8.7 重复运行会不会导入重复的模型？

不会。同一个站点重复导入只会更新原来的条目，还会自动清理以前导入后不能用的旧条目。

8.8 我的 Key 和令牌安全吗？

导入页面只在你自己电脑上运行（地址是 127.0.0.1），并带一次性口令，其他网站调用不了。平台令牌只在运行时用一下，不会保存。Key 会写进 WorkBuddy 自己的配置文件，WorkBuddy 要靠它来调用模型。这个文件只有你自己的账户能读。

8.9 想换一个中转站或换一个 Key

重新运行本工具，填新的站点地址或者选新的 Key 就行。
